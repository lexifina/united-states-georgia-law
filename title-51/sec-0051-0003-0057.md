# § 51-3-57. Liability of security contractors.
(a) If a security contractor assumes and undertakes a duty to invitees and licensees to keep all or part of a premises of an owner or occupier safe from the wrongful conduct of a third person, the security contractor may be liable for negligent security only in the same manner, to the same extent, and subject to the same limitations and provisions applicable to an owner or occupier contained in this article. In no event shall a security contractor be subject to liability for negligent security to an extent greater than the liability for negligent security of an owner or occupier.
(b) No security contractor shall be liable for negligent security except as provided in this Code section.
(c) Nothing in this Code section shall limit or otherwise affect any claim or remedy of an owner or occupier for breach of contract.
