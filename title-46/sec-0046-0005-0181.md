# § 46-5-181. Definitions.
As used in this article, the term:
(1) "Local exchange carrier" shall have the same meaning as the term "local exchange company."
(2) "Local exchange company" shall have the same meaning as set forth in Code Section 46-5-162.
(3) "Long distance service" includes interexchange inter-LATA telecommunications service and interexchange intra-LATA telecommunications service.
(4) "Telecommunications company" shall have the same meaning as set forth in Code Section 46-5-162.
(5) "Telecommunications services" shall have the same meaning as set forth in Code Section 46-5-162.
