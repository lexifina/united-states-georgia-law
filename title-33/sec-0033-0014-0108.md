# § 33-14-108. Applicability of certain provisions of this title.
The following provisions of this title shall not apply to a limited purpose subsidiary organized under this article:
(1) Code Section 33-3-6;
(2) Code Section 33-3-7;
(3) Code Section 33-3-8;
(4) Code Section 33-7-14;
(5) Article 2 of Chapter 11;
(6) Code Section 33-13-4;
(7) Code Section 33-13-5;
(8) Code Section 33-14-40; and
(9) Chapter 56.
