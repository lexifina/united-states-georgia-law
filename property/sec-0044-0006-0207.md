# § 44-6-207. Definitions.
As used in this article, the term:
(1) "Court" means a court of competent jurisdiction as determined in accordance with Code Section 53-12-6.
(2) "Power of appointment" shall have the same meaning as set forth in Code Section 53-12-500.
(3) "Power of direction" shall have the same meaning as set forth in Code Section 53-12-500.
(4) "Trust" means an express trust, as such term is defined in Code Section 53-12-2.
